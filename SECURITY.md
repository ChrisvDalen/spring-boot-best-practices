# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x     | Yes       |

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

Report security issues by emailing the maintainer directly. You will receive a response within 72 hours. If the issue is confirmed, we will:

1. Work on a fix and a release timeline with you.
2. Notify you when the fix is released.
3. Credit you in the release notes (unless you prefer otherwise).

## Disclosure Policy

We follow coordinated (responsible) disclosure. Please allow us a reasonable amount of time to fix the issue before making it public.
